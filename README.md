# Sumeet Kumar Shaw Portfolio

Personal portfolio built with React and Vite.

## Local development

1. Install Node.js and npm from https://nodejs.org/
2. Run `npm install`
3. Run `npm run dev`

## Build for production

Run `npm run build`.

## Deploy to GitHub Pages

1. Push this project to a GitHub repository.
2. Run `npm install` to install dependencies.
3. Run `npm run deploy`.
4. Your site will be published to the `gh-pages` branch and available at `https://<username>.github.io/<repo>`.

## Notes

This portfolio uses a bold blue/teal theme and includes sections for About, Experience, Skills, Projects, and Contact.
